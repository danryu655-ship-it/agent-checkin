# AgentCheckin

Daily check-in badges for Agent ID holders — built for the Binance Agent ID Hackathon (60,000 USDC).

- Free daily check-in, only for Agent ID holders (checked on-chain via the Agent ID registry).
- First check-in mints a Badge NFT; streaks upgrade its tier (7 / 30 days).
- No payments, no token, no promised returns — gas only.
